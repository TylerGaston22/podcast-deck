PPODCAST DECK

Run your podcast's OBS from one small window

Switch layouts, record, change backgrounds, play videos, and bring in hosts from anywhere, with buttons and hotkeys that work while a game has focus.

Download for Windows

Windows 10 or 11. Free. It keeps itself up to date.

  1. Install

    Open PodcastDeck-Setup.exe once it's downloaded. If Windows says it protected your PC, click More info → Run anyway. It puts Podcast Deck on your desktop.

  2. Running the show?

    Install OBS Studio and open it once. In Podcast Deck, click I'm recording, type everyone's name, then open OBS. The deck sets up every layout by itself.

  3. Joining someone's show?

    Open the invite link they sent you. It walks you through everything.

Podcast Deck is open source. See the code.
